# To-Do List

## Description

This is a simple command-line To-Do List application developed using Python as part of the DecodeLabs Python Programming Internship.

The program allows users to add tasks and view all the tasks they have added. It uses Python lists, loops, conditional statements, and user input to manage tasks during program execution.

## Features

- Add a new task
- View all added tasks
- Numbered display of tasks
- Menu-driven interface
- Handles invalid menu choices
- Exit the application

## Technologies Used

- Python 3

## Concepts Used

- Lists
- `append()`
- `while` loop
- `for` loop
- `if-elif-else`
- `enumerate()`
- User input

## How to Run

1. Make sure Python 3 is installed on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python file:

```bash
python todo.py
```

> If your Python file has a different name, replace `todo.py` with the actual filename.
