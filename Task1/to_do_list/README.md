# 📝 To-Do List

## 📌 Description

The To-Do List is a simple command-line application developed using Python as part of the DecodeLabs Python Programming Internship.

This program allows users to add tasks and view all the tasks they have entered. It provides a simple menu-driven interface and stores tasks using a Python list during program execution.

## ✨ Features

- Add new tasks
- View all added tasks
- Display tasks with numbering
- Simple menu-driven interface
- Handle invalid menu choices
- Exit the application

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Used

- Python Lists
- `append()` method
- `while` loop
- `for` loop
- `if-elif-else` statements
- `enumerate()`
- User input using `input()`

## ▶️ How to Run

### 1. Make sure Python is installed

Check your Python installation using:

```bash
python --version
```

### 2. Open the project folder in a terminal

Navigate to the folder containing `to_do_list.py`.

### 3. Run the program

```bash
python to_do_list.py
```
